2. Project Description

GT Movies Store is an online movie store I built for CS 2340. Users can sign up, log in, browse and search for movies, and leave reviews on them, including reporting reviews that are inappropriate. They can also add movies to a cart, place an order, and look back at their past orders. There's an admin page for managing users, movies, reviews, and orders too.

I built it with Python 3.11, Django, and SQLite. It uses Bootstrap for the styling and Pillow for the movie images, and it's hosted on PythonAnywhere.

3. Development Process

How I worked

I followed the book Django 5 for the Impatient chapter by chapter. After each section, I compared my pages to the screenshots in the book before moving on. I worked on it over a few sessions and screen recorded each one while talking through what I was doing.

Fixing problems

When something broke, I started with the Django error page, since it tells you the error, the file, and the line. If a page wouldn't load at all, the problem was usually in the URLs or the view. If it loaded but looked wrong, it was usually in the template or the CSS.

Most of my bugs had the same cause. The book splits long lines of code across two lines so they fit on the page, and typing them in that way breaks them. This happened with HTML, CSS class names, template tags, and Python code. Once I noticed the pattern, the fix was usually just putting the two lines back together.

Staying with SQLite

The book has an optional section on switching from SQLite to MySQL. I read it but stayed with SQLite, since none of the user stories needed MySQL and it made deploying easier.
