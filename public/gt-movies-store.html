2. GT Movies Store

Description

GT Movies Store is a Django web application where users browse a movie catalog, read and write reviews, add movies to a shopping cart, and place orders. It includes user registration and authentication, a session-based cart, full CRUD on reviews, order history, and an admin interface for managing users, movies, reviews, and orders.

Architecture

Django's MVT pattern across four apps:

home
Static pages
movies
Catalog and reviews
accounts
Authentication and orders
cart
Session-based cart

A project-level base template provides the nav, header, and footer; each app supplies its own page templates. Authentication and the admin panel use Django's built-ins.

3. Development Process

Methodology

I followed Django 5 for the Impatient (Correa & Lim) chapter by chapter, building the app incrementally and checking each section's output against the book's figures before moving on. I worked across multiple sessions rather than in one sitting, and I screen-recorded and narrated each session.

How I handled problems

I started from what the page actually told me. Django's error pages name the exception, the file, and the line, so my first step was always to read that carefully instead of guessing. From there I reasoned about which file the problem had to be in: a page that won't load points at a URL pattern or a view, and a page that renders but looks wrong points at a template or the CSS.

Most of the bugs I hit had the same cause. The textbook prints long lines wrapped across two lines to fit the page width, and typing them in exactly as printed breaks them. HTML attributes, CSS class names, Django template tags, and Python statements all fail when a single token is split across lines. Once I recognized the pattern, these bugs were fast to track down: the symptom told me which file to open, and the fix was almost always joining two lines back together.

A scope decision

The textbook offers an optional migration from SQLite to MySQL. I read the section but stayed on SQLite. No user story requires MySQL, SQLite is Django's default, and it keeps deployment simpler.
